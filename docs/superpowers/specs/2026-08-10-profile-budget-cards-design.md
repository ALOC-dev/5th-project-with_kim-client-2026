# 프로필 예산 카드 분리 설계

## 목표

프로필의 단일 `내 월 예산` 카드를 `내 월세 예산`과 `내 전세 예산` 두 카드로 분리해 사용자가 계약 유형별 한도를 바로 구분할 수 있게 한다.

## 표시 방식

- `내 월세 예산`: 월세가 선택된 경우 `보증금 3,000만원 · 월세 60만원 이하`를 표시한다.
- `내 전세 예산`: 전세가 선택된 경우 `전세금 20,000만원 이하`를 표시한다.
- 선택되지 않았거나 필요한 값이 없는 계약 유형은 해당 카드에 `아직 설정하지 않았어요`를 표시한다.
- 두 카드 모두 기존 `변경` 버튼을 제공하고 동일한 예산 설정 화면을 연다.
- 기존 안내 문구와 저장 필드(`maxDeposit`, `maxMonthlyRent`, `maxJeonse`, `leaseTypes`)는 유지한다.

## 범위

- `ProfileSection`의 표시 로직과 마크업만 변경한다.
- 사용자 설정 API, 온보딩 예산 입력, 매물 필터 동작은 변경하지 않는다.
- 모바일에서는 기존 카드 반응형 동작을 그대로 적용한다.

## 검증

- 월세와 전세를 모두 선택하면 두 카드에 각각의 예산이 표시되는지 테스트한다.
- 한 계약 유형만 선택하면 다른 카드가 미설정 상태로 표시되는지 테스트한다.
- 두 변경 버튼이 기존 예산 설정 콜백을 호출하는지 테스트한다.
